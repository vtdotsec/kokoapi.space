Self-hosted Git hosting removes the last important dependency on third-party code hosts.
The modern lightweight options are single-binary Go applications with SQLite or PostgreSQL
backends and built-in web UIs.

They speak the same Git protocol you already use, so migrating repositories is a matter of
a few push commands.
