Generate and scan QR codes without signing up

QR codes are a fast way to move a URL, Wi-Fi credentials, a contact card, an e-mail or an SMS from a screen to a phone. This page generates those codes locally and can also read them back — either with the phone or laptop camera, or from an image you already have. Because the code is drawn in your browser, nothing about its content is sent to a server.

How to create a Wi-Fi QR code

  1. Open Generate and choose Wi-Fi as the content type.
  2. Enter the network name, password and security type (WPA/WEP or open).
  3. Download the PNG and print or display it — scanning it connects the phone.

Frequently asked questions

Is the QR code generator really free?

Yes. The generator is open source and runs entirely in your browser. There are no accounts, no watermarks, no usage limits and nothing to pay.

Does the scanner send my camera feed anywhere?

No. Video frames are decoded on your device and never leave the browser. You can also scan an image file the same way — both paths run locally.

Can I make a QR code for a Wi-Fi network?

Yes. Choose Wi-Fi as the content type, enter the network name, password and security type, and the code will contain the standard WIFI: format that phones recognize.
