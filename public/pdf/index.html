        Merge, split and edit PDF files without uploading them

        The PDF toolkit covers the operations most people need on a PDF: joining several documents into one, splitting out a page range, reordering pages visually, rotating or deleting individual pages, numbering them, adding a watermark, compressing scans and extracting the text layer. Every operation writes a new file that you download — the original is never modified.

        How to combine or split a PDF

        1. Choose Merge in the sidebar and add two or more PDF files, or choose Split to work on a single document.
        2. For a split, enter the pages you want to keep (for example 1, 3-5) or export every page as its own file.
        3. Click the download button — the result is generated locally and saved by your browser.

        Frequently asked questions

        Are my PDF files uploaded to a server?

        No. Every tool reads and writes the PDF inside your browser using client-side libraries. Nothing is sent over the network, so there is no upload size limit to hit and nothing is stored afterwards.

        What happens when I compress a PDF?

        Each page is re-rendered as an optimized JPEG inside a new PDF. The file gets smaller, but text becomes part of the image — compression works best for scans and image-heavy documents, not for text you still need to select.

        Can I remove a password I don't know?

        No. Unlock only works when you already know the password — the file is decrypted locally with the password you type. There is no server that could try passwords for you, by design.

        Does rotating or reordering change my original file?

        No. The tools always produce a new PDF that you download; the file you picked stays untouched on your device.
