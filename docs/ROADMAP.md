# Tools: product direction
Tools is a free, open-source set of useful file operations. Prefer local processing, no accounts, no advertising, no in-app analytics, and honest descriptions of data flows. Cloudflare's account-level traffic dashboard is a separate network metric and is described in the privacy notice.

## Shipped in the interface refresh
- A searchable catalog with direct links to every existing operation; search stays in page memory.
- Shared restrained visual styling across home, PDF, images, conversion and sharing; light by default, dark on demand without stored preferences.
- Smaller navigation and footer, keyboard skip links, visible focus, comfortable touch targets and a live search result count.
- Optional long explanations behind native disclosure controls; working controls keep priority.
- GitHub Sponsors links in the footer and repository funding metadata. The owner must finish Sponsors enrollment before receiving support.
- Task-focused workflows and static guides help visitors complete common photo, PDF, download-check and data-conversion jobs without filling the tool interface with extra explanations.

## Next improvements
1. Improve error recovery and large-file memory estimates before processing; never promise unlimited browser capacity.
2. Add contextual before/after size and quality previews for compression, with predictable output naming.
3. Consolidate duplicate conversion interfaces while preserving existing URLs.
4. Expand keyboard and screen-reader checks for page reordering, cropping, progress and download status.
5. Shipped local SHA-256 checksums, signature-based type inspection and text cleanup with fixtures and privacy tests. A future metadata inspector must clearly distinguish metadata inspection from format signatures.
6. Use Google Search Console query/page reports to choose future guides and decide whether to localize for another language. Do not publish thin translated stubs that lead to an untranslated workflow.
7. Evaluate an explicitly requested offline package. Avoid silently caching documents or introducing service-worker persistence.

## Boundaries
The encrypted sharing service requires temporary server storage and readable delivery metadata. Keep it visibly distinct from local file processing. Sponsor links are plain outbound navigation: no widgets, tracking scripts or automatic third-party requests.
