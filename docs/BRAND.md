# koko tools identity

The wordmark is `koko tools`. The compact k mark uses three strokes inspired by folded file edges. Use the same SVG geometry in site navigation, favicon and social previews; do not add badges or decorative backgrounds to tool controls.

- Primary action: cobalt `#344bc2`, with `#24368e` for hover on light surfaces.
- Light surface: warm neutral `#faf9f6`; main text `#262a38`.
- Dark surface: `#171923`; main text `#eeeff7`; action accent `#b4c0ff`.
- Type: self-hosted IBM Plex Sans for navigation and content; IBM Plex Mono for hashes, signatures and small labels.
- Keep useful work first: a clear task title, one sentence, inputs, an explicit action and a readable result. Longer explanations belong below or in disclosure controls.
- Never communicate match/error states only with color. Keep keyboard focus, descriptive labels and visible status messages.

Assets: `public/_ui/logo.svg`, `public/favicon.svg`, `public/og.svg`. The site shares its visual rules through `public/_ui/minimal.css`.
