Send passwords and notes through links that erase themselves

        

          Secret Sender is for the moments where e-mail or chat is the wrong tool: a
          password for a shared account, an API token, a one-time link to a document, or a
          short log you need to hand to someone. You paste the text or attach a small file,
          pick how long the link lives, and share the generated address. The content is
          encrypted in your browser before it is uploaded, and the key is part of the link
          itself — the server stores only ciphertext and deletes it when the secret expires
          or is read once.

Frequently asked questions

        

          Can the server read what I share?
          

            No. The content is encrypted in your browser before it is uploaded, and the
            decryption key stays in the link after the # sign — the server only
            stores ciphertext and never receives the key.
          

        

        

          What does “burn after one read” mean?
          

            The recipient reveals the content once with an explicit click, and the secret is
            deleted from the server immediately afterwards. A second visit shows an error
            instead of the content.
          

        

        

          What is the size limit for files?
          

            Each payload is limited to 10 MB. The limit is checked in the browser before
            anything is uploaded.
